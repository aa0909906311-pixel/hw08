## 問題回答

### 問題一：為什麼 `"4"` 要先轉成數字，才能用於本題的分攤計算？
因為加上引號的 `"4"` 在 Python 中是字串（`str`）型別，代表文字符號而非數值，無法直接拿來做除法運算（把金額除以字串會產生 `TypeError` 錯誤）。必須先用 `int("4")` 轉成整數（`int`）型別的 `4`，才能正確算出每人分攤的金額。

### 問題二：如果先扣折價券，再依剩餘餐費計算服務費，第一組的應付總額會變成多少？為什麼和題目規定的結果不同？
如果先扣掉 100 元折價券，餐費會變成 `1,200 - 100 = 1,100` 元，再加計 10% 服務費（`1,100 × 0.10 = 110` 元），第一組的應付總額會變成 **1,210 元**（每人 `302.50` 元）。
這和題目規定的 **1,220 元**相差了 10 元，因為餐廳的 10% 服務費是以「原始餐費 1,200 元」為計算基準，折價券是在最後結帳時才折抵；若先扣折價券再算服務費，會連折價券的 100 元都少算了 10% 服務費（`100 × 0.10 = 10` 元）。
